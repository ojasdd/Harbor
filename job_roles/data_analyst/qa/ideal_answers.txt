Question: What is the role of a Data Analyst?

Ideal Answer:
A Data Analyst collects, cleans, processes, and analyzes data to help organizations make data-driven decisions.
Their responsibilities include identifying trends, building dashboards, generating reports, performing statistical analysis, and communicating insights to stakeholders.

Question: What is data cleaning?

Ideal Answer:
Data cleaning is the process of identifying and correcting inaccurate, incomplete, duplicate, or inconsistent data.
Common steps include:
- Handling missing values
- Removing duplicates
- Standardizing formats
- Correcting inconsistent labels
- Detecting and treating outliers
Clean data is essential for accurate analysis and model performance.


Question: How do you handle missing values in a dataset?

Ideal Answer:
Handling missing values depends on the business context and dataset characteristics.
Common methods include:
- Dropping rows or columns with excessive missing values
- Mean, median, or mode imputation
- Forward fill or backward fill for time series
- Predictive imputation using machine learning
The chosen method should minimize bias and preserve data quality.

- Investigating business reasons before removal


Question: Explain normalization and standardization.

Ideal Answer:
Normalization rescales data to a fixed range, usually 0 to 1.

Formula:
X_new = (X - X_min) / (X_max - X_min)

Standardization transforms data to have mean 0 and standard deviation 1.

Formula:
Z = (X - mean) / standard deviation

Normalization is useful for bounded data, while standardization is useful when data follows a normal distribution.

Question: What is the difference between WHERE and HAVING?

Ideal Answer:
WHERE filters rows before aggregation.

Example:
SELECT * FROM employees WHERE salary > 50000;

HAVING filters groups after aggregation.

Example:
SELECT department, COUNT(*)
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;


Question: What is the difference between INNER JOIN and LEFT JOIN?

Ideal Answer:
INNER JOIN returns only matching rows from both tables.

LEFT JOIN returns all rows from the left table and matching rows from the right table.
If no match exists, NULL values are returned for right table columns.


Question: What is GROUP BY in SQL?

Ideal Answer:
GROUP BY is used to group rows that have the same values into summary rows.
It is commonly used with aggregate functions like COUNT, SUM, AVG, MAX, and MIN.

Example:
SELECT department, AVG(salary)
FROM employees
GROUP BY department;


Question: What are aggregate functions in SQL?

Ideal Answer:
Aggregate functions perform calculations on multiple rows and return a single result.

Examples:
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()

Question: What is hypothesis testing?

Ideal Answer:
Hypothesis testing is a statistical method used to determine whether an assumption about a population is likely true.

Steps:
1. Define null and alternative hypotheses
2. Choose significance level
3. Compute test statistic
4. Compare p-value
5. Make decision


Question: What is p-value?

Ideal Answer:
A p-value measures the probability of obtaining observed results assuming the null hypothesis is true.

A small p-value, usually less than 0.05, suggests strong evidence against the null hypothesis.

Question: What are window functions in SQL?

Ideal Answer:
Window functions perform calculations across a set of rows related to the current row without collapsing them into a single output like GROUP BY does.

Syntax: function_name() OVER (PARTITION BY col ORDER BY col)

Common window functions:
- ROW_NUMBER() assigns a unique sequential number to each row
- RANK() assigns rank with gaps for ties
- DENSE_RANK() assigns rank without gaps for ties
- LAG() accesses data from a previous row
- LEAD() accesses data from a following row
- SUM() OVER() calculates a running total

Example:
SELECT name, salary,
RANK() OVER (PARTITION BY department ORDER BY salary DESC) as salary_rank
FROM employees;
